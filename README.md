## Lab 1: Нормальные алгорифмы Маркова

Интерпретатор нормальных алгорифмов Маркова с консольным меню.

### Классы

- Alphabet — алфавит (множество символов)
- Rule — правило подстановки
- MarkovAlgorithm — сам алгоритм (композиция алфавита, правил и ленты)
- ConsoleMenu — консольное меню

### Тесты

58 unit-тестов (GoogleTest).
Покрытие логики: ~100%.

### Документация

Doxygen (HTML-отчёт генерируется в lab1/markov/docs/html/index.html).

### Сборка и запуск

Откройте терминал в корне репозитория и выполните:

1. Перейти в папку проекта:
   cd lab1/markov

2. Настроить сборку:
   cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug

3. Собрать проект:
   cmake --build build

4. Запустить программу:
   ./build/markov
